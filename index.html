01 PROJECT OVERVIEW

One workspace from brief to follow-up

A solo freelancer often reads briefs in one place, drafts in another and tracks replies somewhere else. I wanted to bring those steps together, make it easier to compare work by skill and scope, and keep the final decision with the person doing the work.

Built for independent freelancers

A single-user workspace for developers, illustrators and other freelancers who want to turn a stream of briefs into a manageable list of next actions.

03 CORE FEATURES

A workspace for the full application cycle

01

Freelance job discovery

Sync open Freelancehunt projects through API v2. Import a Freelancehunt link or add a brief from another platform manually.

02

Job classification

Sort by date, budget or skill fit. Rule-based categories let illustration and programming overlap when a brief covers both.

03

AI-assisted analysis

The local baseline estimates skill fit and effort. An optional language model adds risks, scope gaps and questions to ask.

04

Proposal editor

Build an editable draft using the profile’s experience and relevant work. Review the estimate, adjust the text or translate it before using it.

05

Application tracking

A four-stage Kanban board tracks deadlines, values and communication notes. The dashboard summarizes activity and completed project value.

06

Profile & portfolio

Maintain skills, services and work samples. Mark demo work explicitly and export a standalone HTML portfolio.

07

Marketplace API integration

Bearer-authenticated requests, project-ID deduplication and an update trail. A single-bid submission path requires an explicit confirmation.

08

Local workspace

SQLite stores project records and history. A single local account unlocks encrypted API credentials after sign-in.

05 TECHNICAL ARCHITECTURE

A local web stack packaged for Windows

The launcher starts a loopback-only service and opens the built UI in the default browser.

Windows x64C# GUI launcher · bundled Python · Inno Setup
Browser UIReact · TypeScript · Vite
Local API and business logicPython · FastAPI · Uvicorn · HTTPX
SQLiteJobs, proposals, profile and event history
Freelancehunt API v2Project reads and bid endpoint
Optional LLM APIOpenAI-compatible chat completions

Credentials at rest

The local account derives a key from the password with scrypt. Fernet encrypts the credential vault in SQLite. Signing in unlocks credentials for the running session.
